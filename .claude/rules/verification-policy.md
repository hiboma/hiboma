# 検証ポリシー

スクリプトの実行やコンパイルを伴う検証を行う際のルールです。

## 原則: Docker コンテナで検証する

- Linux 環境での検証は Docker コンテナを起動して実施します
- ホスト環境を汚さず、再現性のある検証を行うためです
- Linux カーネルの古いバージョンでの検証はコストが高いため、対応しません

## 例外: macOS 固有の検証

- macOS 固有の挙動を検証する場合は、ホストの macOS で直接実行します
- Docker の Linux コンテナでは macOS の挙動を再現できないためです
- 実行時はプロジェクト配下の `tmp/` ディレクトリを作業場所として使用し、影響範囲を限定します
- `$TMPDIR` や `/tmp` は sandbox 制限があるため使用しません

## 作業ディレクトリ

- 検証用の一時ファイルは `tmp/` 配下に配置します
- `tmp/` は `.gitignore` に登録済みです
